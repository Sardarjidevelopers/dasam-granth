# Sri Dasam Granth Sahib reader

Open it: https://sardarjidevelopers.github.io/dasam-granth/ (installable, works offline).

- Only the bani is included: no commentary and no editor's footnotes.
- Text is extracted from a printed edition and kept exactly as printed. Lines marked ⚑ need checking.
- Ram Avtar (not in that edition) is taken from BaniDB (banidb.com) and checked against a scanned copy.
- English meanings are DRAFTS, written from the bani itself, and are marked as such in the app.
- Punjabi meanings are the Punjabi translation published on BaniDB (banidb.com), matched to the lines here by text; they are shown with that source. Lines that could not be matched have none.
- Roman transliteration is rule-based.
- Gurmukhi font: Noto Sans Gurmukhi, SIL Open Font License (fonts/OFL.txt).

This repository is generated; changes are made in the source project, not here.
